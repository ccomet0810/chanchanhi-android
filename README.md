# 찬찬히 3

스마트폰 조작이 익숙하지 않은 사람이 원하는 일을 직접 해낼 수 있도록, 사용 중인 Android 화면 위에서 다음 행동을 알려주는 앱입니다.

“알람 맞추고 싶어”처럼 평소 쓰는 말로 요청할 수 있습니다. 찬찬히는 지금 화면에서 조작할 위치를 강조하고, 누르거나 밀어야 할 방향을 짧은 문구와 음성으로 알려줍니다. 입력, 선택, 저장, 전송은 사용자가 합니다.

## 지금 어디까지 만들었나요?

`3.0.0-dev`는 실기기에 설치해 볼 수 있는 개발 버전입니다. 현재는 Android 접근성 서비스에서 화면의 요소와 상태를 읽습니다. 대상 앱에서 필요한 항목이나 완료 근거를 확인하기 어려우면 안내를 보류하거나 화면을 다시 확인합니다. 화면 이미지나 OCR로 부족한 정보를 보완하는 방법은 별도로 실험 중입니다.

## 한 번의 안내가 진행되는 방식

1. 사용자가 음성이나 글로 원하는 일을 요청합니다.
2. 접근성 정보와 현재 목표를 바탕으로 필요한 작업, 선택지, 완료 조건을 계획합니다. 다음 안내에 필요한 정보가 부족할 때만 질문합니다.
3. 앱이 현재 화면에서 안내 대상을 다시 확인하고, 사용자가 할 행동 하나를 표시합니다. 사용자가 작성하거나 화면이 전환되는 동안 진행을 기다립니다.
4. 화면이 바뀌면 다시 관찰합니다. 사용자가 수행한 행동과 결과를 구분해, 목표가 충족됐다는 근거를 확인한 뒤 안내를 끝냅니다.

[V3 설계와 다이어그램](docs/guidance-design.md)에서 계획, 사용자 대기, 중단, 복구, 완료 검증을 살펴볼 수 있습니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `app3/` | 설치 대상 Android 앱, V3 판단 엔진과 테스트 |
| `app/` | V3가 가져오는 공통 Android 코드 |
| `app2/` | V3가 가져오는 Compose UI, 리소스, Android 서비스 구현 |
| `subscription-bridge/` | 구조화된 `task_plan` 요청과 응답을 처리하는 브리지 및 테스트 |

## 빌드 및 검증

Android Studio에서 이 저장소를 엽니다. JDK 17 이상과 Android SDK Platform 36이 필요합니다. Gradle 모듈은 `app3`을 선택합니다. 앱의 최소 실행 버전은 Android 8.0입니다.

```powershell
.\gradlew.bat :app3:assembleDebug :app3:testDebugUnitTest :app3:lintDebug
```

macOS와 Linux에서는 `./gradlew`를 사용합니다. 디버그 APK는 `app3/build/outputs/apk/debug/app3-debug.apk`에 생성됩니다.

휴대폰에 설치한 뒤 접근성 설정에서 **찬찬히 3 화면 안내**를 켜고, 기본 디지털 어시스턴트 앱으로 **찬찬히 3**을 선택합니다. 음성 입력을 쓰려면 마이크를 허용합니다. AI 안내를 사용하려면 팀에서 제공한 HTTPS 브리지 주소와 개인 연결 키를 앱의 **설정 → AI 연결**에 저장합니다. 현재 팀 테스트 구성은 승인된 구독 연결의 Terra 6.1 low를 사용합니다.
